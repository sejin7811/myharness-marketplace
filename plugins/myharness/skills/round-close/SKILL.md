# 라운드 종료

아래를 순서대로 진행한다. 하나라도 안 되면 끝났다고 보고하지 않는다.

1. **문서 대조**: 이번 라운드의 spec · plan · review 문서(예: `docs/roundNN/`)가 지금 코드와 맞는지 확인하고 고친다.
2. **진실의 원천 갱신**: `docs/SSOT.md` 같은 기준 문서를 지금 코드 기준으로 고친다. (현재 라운드, API 목록, 데이터 모델)
3. **정리**: `cleaner` 에이전트로 죽은 코드를 정리하고, 결과를 review 문서에 적는다.
4. **검증**: `verifier` 에이전트로 spec 기준 검증을 받고, 프로젝트의 테스트 · 린트 명령이 통과하는지 확인한다.
5. **로드맵 표시**: 로드맵 문서(예: `docs/ROADMAP.md`)에서 이번 라운드를 완료로 표시한다.

프로젝트에 위 문서가 없으면 해당 단계는 건너뛰었다고 보고한다.
Hook에 막힌 작업은 다른 명령으로 우회하지 말고 멈춰서 사람에게 보고한다.
